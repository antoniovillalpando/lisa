# Análisis complementario

Este directorio contiene la versión depurada de los análisis exploratorios y productos auxiliares utilizados en el **Atlas de Riesgos para la Nutrición de la Niñez en México**.

El código integra en un solo flujo procedimientos que originalmente se encontraban distribuidos entre distintos scripts.

## Script principal

`04_analisis_complementario.R`

## Contenido

El script comprende:

- regresiones exploratorias univariadas;
- selección de variables mediante procedimientos forward;
- análisis de componentes principales;
- identificación de variables relevantes por componente;
- selección de subconjuntos de variables;
- elaboración de tablas y gráficas de factores importantes.
