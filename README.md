# Laboratorio de Investigación Social Avanzada

**LISA** es un espacio dedicado al desarrollo, revisión y difusión de investigación social aplicada, con énfasis en métodos cuantitativos, análisis territorial y evaluación de políticas públicas.

## Proyectos

### Atlas de Riesgos

Proyecto de revisión metodológica y reproducción de un modelo de riesgos basado en **XGBoost**.

El proyecto reunirá:

- Los scripts de R utilizados para construir y ejecutar el modelo.
- Una auditoría metodológica y computacional del modelo XGBoost.
- El estudio original en formato PDF.
- Una guía de las bases de datos empleadas.
- Los resultados y materiales derivados del proceso de revisión.

La documentación completa del proyecto estará disponible próximamente.
